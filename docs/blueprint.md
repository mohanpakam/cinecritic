# **App Name**: RxConnect

## Core Features:

- Secure Login: Secure login/authentication for doctors and vets.
- Patient/Pet Management: Upload and manage patient/pet records with client info.
- New Rx Submission: Send new prescriptions to pharmacies electronically.
- Rx Approval Workflow: Receive prescription requests from pharmacies and approve/deny them.
- Rx History: Review the history of prescriptions for a specific patient/pet or all prescriptions.

## Style Guidelines:

- Primary color: Teal (#008080) to convey trust and health.
- Secondary color: Light gray (#F0F0F0) for clean backgrounds.
- Accent: Green (#90EE90) for key actions and highlights.
- Clean and intuitive layout with clear navigation for ease of use.
- Use recognizable medical icons for common actions.
- Subtle animations to indicate loading and successful actions.

## Original User Request:
Create the front end application that includes a great Hero/landing page for doctors and Vets to login and manage their patient's Prescriptions. This should give ability to upload patients/pets with client info, send new RXs to pharmacies and receive rxs from pharmacies and approve them. Review the history of a patient/pet or review the history of all RXs approved for new or refill requests. Ask me any questions.
